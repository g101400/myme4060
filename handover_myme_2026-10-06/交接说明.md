## 四、老坑备忘录（下次接手先看）

- **端口服务起不来别急**：Git Bash 里 `cmd &` / `nohup ... &` 起的 python，工具调用一结束就被回收；
  跨调用存活要用 Windows 原生托管启动，或把「起服务 + 打接口」放同一条命令里闭环。
- **502 ≠ 服务 bug**：本机环境有代理，urllib/curl 走代理时，服务已死会被包装成
  "502 Bad Gateway / upstream connect failed"，先 `tasklist` 看进程、`netstat` 看端口，再判断。
- **改完源码要同步打包副本**（`dist_pkg/myme-ios-pwa/`），否则「源码改了、产物还是旧的」。
- 长链路（PPT / 思维导图 5~10 分钟）一律后台跑 + 阻塞等待，前台一定被超时杀。

### 3.3 使用提示

- **多源导入**：菜单「📥 多源导入」→ 链接采集（公众号/网页/微博一行一个）/ 粘贴正文 / 本地文档 /

  便携播放包 / 全部资源 / 答疑汇总。

  不用再整包解压；包内 media 走 blob URL，同包在 Win / 安卓 / 统信都能播。
