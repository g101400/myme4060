## 二、行为变化（用户可感知）

### 2.1 播放端

| 场景 | 旧行为 | 新行为 |
|---|---|---|
| 包内只有炎冰的配音，用户选「金子」 | 照放，出的是**炎冰的声音**配金子的脸 | 金子项标「仅画面」并置灰；顶部提示「「金子」仅有画面无配音」 |
| 用户选「金子 · 英文」，但金子没英文配音 | 英文照选，播炎冰英文 | 英文项标「· 无」置灰；自动回落中文；弹「「金子」没有英文配音，已切到中文（本包英文配音是「炎冰」的）」 |
| 老包（v2.9.4 及以前导出） | — | **不误判**：无 `voices`/`audio_person` 时一律可选，靠逐页提示兜底 |
| 某页图缺失 | 清单硬写 `images/p01.png`，包里没有 → 一片空白 | 导出时就不写这条引用（`img` 置空），播放端回退纯文本版式 |

- ④ 生成讲解：多了「讲解分身（声音）」下拉 + 一行说明（本次用谁的声音、什么语言、会同时出英文讲稿）。

3. **GitHub Release 二进制**：若 `api.github.com` 不可达，改用 `gh release create` 在构建机补建。

## 七、本轮的"假失败"教训（重要，别再误判）

| 现象 | 真相 |
|---|---|
| `wix build` 退出码 0 但"没出文件" | 产出了，只是被 Git Bash 折叠成 8.3 短名 `dist/MYME-S~1.MSI`。真身完好：OLE 头 `d0cf11e0`、`ProductVersion=2.9.5`、内嵌 `myme.exe`。已 `mv` 回长名，门禁加了三重判据。 |
| APK 158 MB（应为 46.9） | `copytree(dirs_exist_ok=True)` 只覆盖不删，上一版大图/音频还躺在 `android-player/assets/`。已改为复制前清空。 |
| 门禁 `versionCode==10` 红 | `_gate_292.py::EXPECT_VCODE` 没跟 `AndroidManifest.xml` 一起 +1。已 → 12，并写进升版清单。 |
| 播放器菜单渲染半途而废 | `refreshAvailability()` 调了不存在的 `segOf()`，抛错打断 `applyParams()`。已改 `segByPL()` + 三段 `try/catch`。 |

**统一结论**：出包/门禁判断**以产物内部证据为准**（OLE 头、Property 表、dex 里的方法名、包内文件字节），
不要只看退出码、文件是否存在或文件名。
