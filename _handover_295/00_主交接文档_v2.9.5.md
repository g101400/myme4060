## 2. 本轮（v2.9.5）到底改了什么

### 2.1 治本：声音归属从"隐式"变"显式"

以前每个播放包只有**一份**中文配音、**一份**英文配音（都是生成时那个分身的声音），
但导出清单里却列了「炎冰·中文 / 炎冰·英文 / 金子·中文 / 金子·英文」四段 ——
于是「金子·中文」是**炎冰的嗓子 + 金子的脸**。这就是用户说的"串和混乱"。

现在：

| 位置 | 改动 |
|---|---|
| `app.py::_job_worker` / `_job_worker_version` | 合成时把 `audio_person`（中）/ `audio_person_en`（英）写进每一页 |
| `app.py::_build_segments` | 逐人逐语言算 `ready` / `missing` / `voice_ok`；缺配音写「本包配音是「炎冰」的声音」 |
| `app.py::_build_manifest` | 输出 `pages[].audio_person(_en)`、`params.voice_person`、`params.voices = {分身:{zh,en}}` |
| `ui/player.html` | `voicesMap()` / `hasVoice()` / `voiceOwner()` / `canPlay()` / `refreshAvailability()` |
| `ui/index.html` | ④生成讲解 + 新增讲解版本 增加「讲解分身（声音）」下拉；导出对话框加 `voice` 标注行 |

### 2.2 三层判定（缺哪层都不算合格）

```
canPlay(person, lang):
  ① 整包有没有这种语言      ← params.langs（判不出来则放行，不误判老包）
  ② 这个人有没有这种语言    ← params.voices，退化到逐页 audio_person
  ③ 该片段是否齐            ← segments[].ready，缺页只提示不拦播
→ 灰选 + 文字标注「· 无」/「仅画面」+ title 写原因 + 顶部 #mHint 汇总
→ 若当前语言被灰掉：自动回落到可用语言，并弹一句"本包该语言配音是 X 的"
```

### 2.3 绝不静默顶替（最后一道闸）

`play()` 里逐页再核一次：本页 `audio_person` 与当前选中的分身不一致时，
**当场 toast 说明"这一页是 X 的声音"**，不允许"看起来无缝、实际换了人"。

### 2.4 视觉一致性收口

- 主程序：清掉残留蓝色投影 `rgba(29,78,216,…)`（4 处）、蓝调背景 `rgba(46,125,255,…)`（2 处）、
  进度条蓝渐变 `#60a5fa` → 青绿。
- 播放器：**首块 `:root` 的旧蓝 `#4f8cff` / 深底 `#0b1020` 改为青绿 `#0f766e` / 浅底 `#f1f5f9`**
  （此前靠后文覆盖块才生效，属"删掉覆盖块就变蓝"的定时炸弹）。

## 4. 出包命令（本机已验证可实出）

```bash
python3 sync_version_info.py                 # version_info.txt ← config.VERSION
python3 pack_portable.py bundle deb apk      # 示例播放包 + deb×5 + apk
python3 pack_portable.py win                 # Win 便携 zip（需先有 dist/myme-play.exe）
python3 build_ios_zip.py                     # iOS PWA zip
python3 -m PyInstaller myme.spec --noconfirm --clean            # dist/myme.exe
printf '' > playback.mode && python3 -m PyInstaller myme_portable.spec --noconfirm --clean && rm playback.mode   # dist/myme-play.exe
wix build myme.wxs -o "dist\\myme-2.9.5-win-x64-setup.msi"   # 精简 MSI（单文件 myme.exe，perUser 免管理员）
makensis //V2 myme_setup.nsi                # NSIS EXE 版（同一份 myme.exe，双保险）
python3 pack_full.py                        # 完整 MSI（含 LivePortrait+ts_deps，668 MB，视机器内存而定）
```

> **Git Bash 下出 MSI 的两个坑（2026-10-18 实测）**
> 1. 输出名会被折叠成 8.3 短名 —— `dist/myme-2.9.5-win-x64-setup.msi` 实际落成 `dist/MYME-S~1.MSI`。
>    出包后必须 `ls dist/*.MSI` 核对，再 `mv` 回长文件名。**看返回码 0 就当成功 = 会误判"没出文件"**。
> 2. `-o` 的路径在 Git Bash 里要么写 `"dist\\xxx.msi"`（双反斜杠），要么直接 `cd dist` 后在当前目录出。
>    门禁 Layer 3d 已加硬判据：MSI 必须有 OLE 头 `d0cf11e0`、内嵌 `ProductVersion`、含 `myme.exe`、且无 `MY*~*.MSI` 残留。
>
> 本机实测：`myme-2.9.5-win-x64-setup.msi`（21 MB，WiX 7.0.0）与
> `myme-2.9.5-win-x64-setup.exe`（21 MB，NSIS）**两份都真实产出且可装**。

**工具链（本机已核）**：WiX 4 CLI（`C:/Users/admin/.dotnet/tools/wix.exe`）、
NSIS（`C:/Program Files (x86)/NSIS/makensis.exe`）、Android SDK 34（aapt2/d8/apksigner）、

## 5. 铁律（违反即返工）

1. **脸 / 声音 / 语言三方同源**，缺的组合灰选 + 写原因，绝不静默顶替。
2. `ui/player.html` 与 `android-player/assets/player.html` **字节一致**（门禁断言 MD5）。
3. 版本号只改 `config.py::VERSION`，其余（wxs / manifest / version_info / 徽标 / 包名）跟着同步。
4. **功能只增不减**：13 标签、9 阶段向导、七项产出、四片段播放、深度加工四项、便携三端导出一个都不能少。
5. 三端视觉同一套 token：藏青 `#0f172a` + 青绿 `#0f766e` / 辅色 `#14b8a6`，**不得再出现靛蓝/旧蓝字面量**。
6. 出包脚本"校验没通过"必须**非零退出**，不许打印 ❌ 后继续。

## 6. 已知坑（都踩过，别再踩）

| 现象 | 根因 | 对策 |
|---|---|---|
| 统信装了打不开 / 白屏 | 旧 sh 启动器用 `curl` 探就绪，而 curl 对任何 HTTP 应答都返回 0；内网代理把 127.0.0.1 变 502 → 误判"已运行"→ 服务根本没起 | 已改为 `deb_assets/launch.py`：显式空代理 + magic token `/__myme_ping__` 必须回 `myme-player-ok`；`no_proxy` 写死 127.0.0.1/localhost/::1 |
| 统信点图标没反应、无报错 | 精简 rootfs 无 `setsid`；诊断只 echo 到 stdout（无终端） | `Popen(start_new_session=True)`；失败出中文诊断页 + 桌面通知 + `/tmp/myme-player.log` |
| dpkg 挑不着包 | `Architecture: all` 通吃但 dpkg 按架构判可装 | 逐架构出包，control 与文件名必须一致（门禁断言） |
| 安卓「导入」子菜单点了没反应 | WebView 的 `input[type=file].click()` 必须宿主 `onShowFileChooser` 转交 | 原生壳已补；点之前先告诉原生桥"选文件夹"意图 |
| 源码改了、包里没改 | 复用旧 `C:/tmp/myme_pkg/portable`，里面的 `player.html` 是上一版 | `ensure_bundle()` 每次强制从 `ui/player.html` 覆写 + 门禁断言 |
| 换机后「分身形象」下拉为空 | `avatar_out/portraits` 跟着项目目录走，新机为空 | 到「⑤ 制作视频 → 分身管理」重新加人加图，或从旧机拷 `persons.json` + 图片 |
| APK 从 46 MB 虚胖到 158 MB | `build_apk()` 用 `copytree(dirs_exist_ok=True)` 只覆盖不删，上一版大图/音频全留在 `assets/` | 复制前先清空 assets（保留目录）。已修；出包后对体积做上限断言 |
| MSI 明明出了却"找不到" | Git Bash 把长文件名折叠成 8.3 短名（`MYME-S~1.MSI`），返回码还是 0 | 出包后 `ls dist/*.MSI` 核对 + `mv` 改回；门禁已加 OLE 头/ProductVersion/残留三重判据 |
| 门禁报 `versionCode==10 断言失败` | `_gate_292.py::EXPECT_VCODE` 要手动跟 `AndroidManifest.xml` 一起 +1（本轮 11→12） | 升版清单里把这两处绑成一条：改 manifest 必改门禁常量 |
